# Tuviagame

Funny Hebrew (RTL) browser game for Tuvia Tenenbom fans. Read PLAN.md first: it holds every decision from the interview with the user.

Workflow:
1. Write SPEC.md on `main` (creative, in Tuvia's voice, rich Hebrew sample dialogue).
2. Then build 4 fully independent prototypes on branches `novel`, `walker`, `catcher` and `mix`.
3. Add a landing page plus a GitHub Action on `main` that deploys all 4 branches to GitHub Pages.

Rules:
- Never commit the reference photo of Tuvia. It goes in `reference/`, which is gitignored.
- Public figures appear only as renamed parodies, mocked for public positions and habits only.
